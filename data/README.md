# Dataset Documentation

## Dataset Information

- Name: DPWH Infrastructure Transparency Dataset
- Source: https://data.bettergov.ph/
- Original format: Parquet
- Working format: CSV
- Records: 248,220
- Fields: 23

## Proposed Task

Predict infrastructure project budgets using historical project characteristics.

Potential features include project category, region, and infrastructure year.

Target variable: budget

## Data Preparation

The original Parquet dataset was converted to CSV for inspection.
